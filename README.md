# Text to Voice Converter 🎙️

A web-based Text-to-Speech application built using Streamlit and gTTS (Google Text-to-Speech).

## Features
- Converts custom text input into clear spoken audio.
- Supports multiple language selections.
- In-browser audio playback.
- Option to download generated speech as an MP3 file.
